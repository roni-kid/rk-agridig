## Project

RK AgriDig is a fully offline crop disease diagnosis assistant built for smallholder
farmers in Ghana, running Phi-3-mini-4k-instruct (Q4_K_M quantized) via llama.cpp/Ollama
on commodity 8GB laptop hardware — no cloud dependency, no internet requirement in the field.
